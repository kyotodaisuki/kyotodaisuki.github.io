# kurogiの技術ブログ

Javaの保守、Linux、Python、ROS2の学習記録です。
自動運転ソフトウェアの結合検証エンジニアを目指しています。

## 記事

- 保守環境における大規模CSVインポートのタイムアウト対応

記事はすべて匿名化しています。会社名、顧客情報、プロダクションコードは含みません。

## 新しい記事の書き方

1. `_posts`フォルダに新しいファイルを作ります。
2. ファイル名は `2026-11-02-タイトル.md` のようにします。
3. 最初に次の情報を書きます。

```yaml
title: "タイトル"
date: 2026-11-02
categories:
  - Java
tags:
  - CSV
excerpt: "一言の説明"
```

4. 本文はMarkdownで書きます。

## 公開方法

GitHub Pagesで公開しています。

1. Settings → Pages を開きます。
2. Source は Deploy from a branch を選びます。
3. Branch は main、フォルダは /(root) を選びます。
4. Save を押します。
